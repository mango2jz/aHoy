Following render_page

Step 10 Mode Safe 6 tool calls High confidence 14:31

render_page is the last stop before the browser. Like a waiter, it fetches a Page from the database, plates it as safe HTML and serves it to page.html.

Key points

  • Only the /wiki/<slug> route calls it.
  • It also collects backlinks: the pages that link to this one.
  • Markdown is sanitised first, so templates never see raw user text.
