Command mode

How shell commands are handled in your next steps. Reading files and searching work in every mode. Press Shift+Tab in a session to cycle it.

Safe-mode allowlist

Programs the crew may run in Safe mode. A git entry also names its subcommand. Arguments are free, except the flags listed below.

  • lslist a folder
  • catprint a file
  • headfirst lines
  • taillast lines
  • wccount lines
  • findfind files
  • treefolder outline
  • rgsearch, fast
  • grepsearch
  • git statusworking tree
  • git loghistory
  • git diffchanges
  • git showone commit
  • git blamewho changed a line
Always blocked in Safe mode, even for listed programs

Chaining, pipes and redirects: ; && || | > < ` $( and newlines. Plus these flags, which can run other programs or write files:

Sessions I can no longer open

None. If you lose access to a repo on GitHub, its sessions move here so you can delete them.

Delete my account

Removes all your sessions, waypoints, settings and GitHub tokens from aHoy, and revokes its access on GitHub. This cannot be undone.

In every mode

  • A step never stops to ask you. It ends as one waypoint or one error.
  • Commands run in a throw-away sandbox: no network, an empty environment, and the repo mounted read-only.
  • .env* *.pem *.key id_* are deleted from every snapshot and refused by name.
  • Git history is not filtered. A secret committed in the past is still in it; Auto mode can reach it.
